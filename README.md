### Home Row Mods

BASE:

- `S / L` → Shift
- `D / K` → Ctrl
- `F / J` → Cmd
- `A` → Alt (Right)


HMR uses opposite-hand triggering to reduce accidental holds
during normal typing.

Transparent (`&trans`) keys on other layers may intentionally
inherit HMR behavior from BASE.
